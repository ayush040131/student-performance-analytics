# Student Performance Analytics Dashboard

An interactive dashboard built with Python, Pandas, Streamlit, Plotly, and Excel to analyse student marks, attendance, and academic performance.

## 🚀 Live Demo

**[Click here to open the interactive dashboard](https://student-performance-analytics-g24tfmww2s6dpuo7snytur.streamlit.app/)**

## Features

* Student performance and attendance analysis
* Automatic average marks and Pass/Fail calculation
* Subject-wise performance charts
* Attendance versus academic performance visualisation
* Interactive subject and result filters
* Excel-based data loading

## Technologies Used

* Python
* Pandas
* Streamlit
* Plotly
* Microsoft Excel

## Run Locally

1. Clone or download this repository.

2. Install dependencies:

   `pip install -r requirements.txt`

3. Start the dashboard:

   `streamlit run app.py`
